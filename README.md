# 深蓝档案 · OCEAN DOSSIER

一个「滚动即下潜」的海洋保护单页网站：从海面 0 米一路潜到马里亚纳海沟 **10909 米**，
途中认识 12 种海洋生物、看清 5 个正在发生的威胁，并可以直接在画面上把塑料瓶捞出来。

> 制作人：**吴晨**
> 在线预览：**https://gxglad.github.io/ocean-wc/**

---

## 源码结构

| 文件 | 作用 |
|---|---|
| [`index.html`](index.html) | 页面结构、全部文案、12 个海洋生物 SVG 图标精灵（`<symbol>`） |
| [`styles.css`](styles.css) | 视觉样式：水体分层动画、玻璃拟态、深度 HUD、响应式 |
| [`app.js`](app.js) | 交互逻辑：入场序列、深度引擎、画布特效、声呐、发光、分享 |

**纯原生实现**：无框架、无构建步骤、无 CDN 外链，克隆后直接双击 `index.html` 即可离线运行。

## 它是怎么工作的

### 1. 入场序列（canvas）

从海底 10909 米上浮到海面，约 5 秒：

- 近黑蓝的深渊 + 海雪 + 生物发光点（色相随机，模拟深海生物光）
- 穿过五层海域，水色色相由深蓝（224°）连续过渡到青蓝（190°）
- 接近海面时丁达尔光柱逐渐显现，最后破水白闪
- 可点击任意处跳过；**动画不执行也会自动放行，不会白屏**

### 2. 海面背景（8 层叠加）

`#waterviz` 内按 `z-index` 叠了 8 层，全部由 CSS 驱动：

```
水体渐变 → 极光光带 → 焦散光斑 → 丁达尔光柱 → 水面涌浪
        → 海藻林摆动 → 鱼群游动 → 漂浮微粒 → 暗角
```

> ⚠️ 踩坑记录：给容器内的子元素设 `z-index` 时，必须同时给容器加
> `isolation: isolate`，否则子元素会逃出层叠上下文、反过来盖住正文。

### 3. 深度引擎

滚动条就是潜水器。`app.js` 把每个 `[data-depth]` 区块的页面位置映射成米数，
在两点之间做缓动插值，实时驱动右侧深度表、海域名称、水体颜色与里程碑提示。
滚动量为 0 时正好是 0 米。

### 4. 三层画布

| 层 | 内容 | 随深度变化 |
|---|---|---|
| `#fx` | 气泡 / 海雪 / 塑料瓶 | 气泡越深越少，海雪越深越多 |
| `#bloom-canvas` | 水母群生物发光 | 点击「发光」后启用，加色混合 |
| 水体层 | 见上 | 色相与亮度随深度变化 |

## 交互一览

| 操作 | 效果 |
|---|---|
| 滚动 | 下潜，深度表实时更新，水体变色 |
| 点「撒一张网」 | 一张网扫过画面，捞走漂过的塑料瓶并计数 |
| 点画面里的塑料瓶 | 直接捞起（带涟漪与气泡反馈） |
| 点「声呐」 | 全站生物图标脉冲高亮，光标变成声呐圈 |
| 点「发光」 | 点亮水母群，海色转为繁盛状态 |
| 悬停「动手 / 照旧」两栏 | 整片海的颜色随之在繁盛 / 死寂之间切换 |
| 点「分享这份档案」 | 系统分享 → 剪贴板 → 旧式复制 → 手动复制面板，四级降级必定有反馈 |

## 无障碍与健壮性

- 遵循 `prefers-reduced-motion`：关闭动画、隐藏粒子层、直接显示内容
- 图标均为内联 `<symbol>`，用 `currentColor` 描边，无外部请求
- 多处兜底：入场卡住会自动放行；首屏文字在动画不执行时强制落到终态
- 键盘可达：`Esc` / `Enter` / `空格` 可跳过入场，可见元素均有焦点样式
